# Widgets

Componentes de negocio que nao se encaixam apenas como formulario, botao ou tabela.

## Arquivos

- `checagem-de-cobertura.html`: widget de consulta de cobertura por CEP para Netwave. Traz campo de busca, card de resultado e modal com lista de CEPs com cobertura ativa.
- `vsl-lead-timer.html`: bloco com video estilo VSL e overlay de captura. O usuario preenche nome e WhatsApp para desbloquear ou continuar a experiencia do video.
