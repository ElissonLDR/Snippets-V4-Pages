# Buttons Floating

Snippets de botoes flutuantes que abrem uma interacao mais rica do que um link simples.

## Arquivos

- `floating-button-form.html`: botao flutuante que abre um formulario estilo WhatsApp com campos de nome, CNPJ, WhatsApp, segmento, tipo de cabo e descricao. Tambem captura UTMs e serve para fluxos comerciais onde o clique precisa qualificar o lead antes do contato.
