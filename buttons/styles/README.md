# Button Styles

Snippets pequenos para alterar a aparencia e a animacao de botoes existentes.

## Arquivos

- `button-styles.html`: adiciona um efeito de hover que move o botao alguns pixels para cima. Foi pensado para classes como `.e_botao` e `.gpc_botao`.
- `blinking-button.html`: aplica animacao de pulso e sombra alternada para deixar o botao mais chamativo. Ideal para CTA principal de landing page.
