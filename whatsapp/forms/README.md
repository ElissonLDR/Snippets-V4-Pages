# WhatsApp Forms

Snippets de formularios que qualificam o lead antes de abrir o WhatsApp ou enviar dados para automacoes.

## Arquivos

- `whatsapp-floating-form.html`: widget flutuante com formulario simples de nome, telefone e mensagem. Serve para iniciar uma conversa no WhatsApp com dados basicos ja preenchidos.
- `whatsapp-floating-webhook_make.html`: widget flutuante com formulario comercial mais completo. Coleta CNPJ, tipo de cabo, volume, segmento e urgencia, sendo indicado para fluxos integrados com webhook no Make.
- `floating-form-whatsapp.html`: formulario focado em leads B2B, com campos de nome, CNPJ, WhatsApp, segmento, tipo de cabo e descricao. Tambem captura UTMs para rastreamento de origem.
