# WhatsApp

Snippets focados em captacao, contato e automacao via WhatsApp.

## Subpastas

- `buttons/`: botoes simples para abrir conversa.
- `forms/`: formularios que coletam dados antes de abrir o WhatsApp ou acionar automacoes.
- `redirects/`: fluxos que enviam e redirecionam para conversa.
- `widgets/`: widgets flutuantes prontos para fixar na tela.
