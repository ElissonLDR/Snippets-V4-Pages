# WhatsApp Redirects

Snippets que combinam formulario, envio de dados e abertura de conversa no WhatsApp.

## Arquivos

- `whatsapp-form-redirect.html`: formulario de solicitacao tecnica com captura de UTMs, validacao de campos, envio para `WEBHOOK_N8N` e `WEBHOOK_MAKE` e abertura automatica de uma conversa no WhatsApp com mensagem montada a partir dos dados do usuario.
