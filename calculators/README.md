# Calculators

Snippets com logica de simulacao e calculo para captar ou qualificar leads.

## Arquivos

- `movisat-calculator.html`: calculadora de economia potencial para frotas. Coleta dados como quantidade de veiculos, km medio, preco do combustivel e horas de ociosidade, exibe relatorio em modal e funciona como etapa de captacao antes da conversao.
