# Forms

Esta pasta guarda snippets de formulario separados por responsabilidade.

## Subpastas

- `projects/`: formularios feitos para clientes ou casos especificos.
- `redirects/`: scripts de redirecionamento disparados por condicao dentro do formulario.
- `templates/`: modelos prontos para duplicar e adaptar.
- `validation/`: mascaras e validacoes reaproveitaveis.
