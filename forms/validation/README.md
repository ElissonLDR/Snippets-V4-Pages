# Forms Validation

Snippets reutilizaveis para mascara e restricao de entrada em campos de formulario.

## Arquivos

- `phone-mask.html`: aplica mascara de telefone brasileiro usando jQuery e Inputmask em um campo especifico pelo ID `#input_1744058939`.
- `numeric-validator.html`: limita a digitacao a numeros com Vanilla Masker, troca o campo para modo numerico e mostra alerta visual quando o usuario tenta inserir caracteres invalidos.
