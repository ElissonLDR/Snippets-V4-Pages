# Forms Templates

Modelos prontos de formulario que podem ser adaptados para novos projetos.

## Arquivos

- `tt-tecnica-form.html`: formulario de agendamento de visita tecnica com etapas, envio por `POST`, mascara de telefone e configuracoes de autoresposta. Precisa ajustar o placeholder `AQUI_LINK_FORM_SUBMIT` antes do uso.
